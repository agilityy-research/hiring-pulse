How these numbers are made

One vocabulary, every description

Each job description is matched against a fixed list of about 480 terms (programming languages, frameworks, cloud and data platforms, business tools, methods, certifications, licences and spoken languages). Short or ambiguous names (Go, R, C) match only in their exact form, so "go to market" is not Go. A skill counts once per description. Roles whose board publishes no description (some Personio and SmartRecruiters boards) are not in these shares; {{ s.coveragePct }}% of the roles with a description are tagged this week. Methodology.
